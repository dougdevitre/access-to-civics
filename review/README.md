# Editorial review sheets

Generated by `npm run review:sheet`. One file per ingested state, pairing every clause's verbatim text with the plain-language glosses and the sensitivity call, so a reviewer can work through it without opening a JSON file.

The clause text is byte-verified on every build and needs nobody's word for it. The glosses and sensitivity calls are editorial judgement that no checksum can check. That is what these sheets are for.
